## Supported profile dimensions

The current product supports skills; target roles and weekly hours; canonical
location and provenance; distance, travel modes and maximum commute time;
employment types, working patterns and workplace arrangements; availability or
notice period; qualifications; roles; and versioned evidence entries/snapshots.

Professional summary, salary expectation, preferred industries, languages,
right-to-work and portfolio fields are not owned by the current User Profile
contract and are therefore not invented in these fixtures.
