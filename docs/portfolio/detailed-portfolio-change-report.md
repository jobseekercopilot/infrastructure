# Detailed portfolio change report

## Baseline retained

The 16-page `Bernard-McGeever-Job-Seeker-Copilot-Technical-Portfolio-2026.pdf` remains the concise v1 portfolio. It is not deleted or overwritten.

## What v2 adds

The detailed engineering edition adds:

- an evidence-derived engineering timeline using Git and GitHub history;
- a complete 31-repository/service catalogue rather than a small representative subset;
- substantially deeper frontend/BFF, identity, profile and Evidence Library coverage;
- provider-by-provider job discovery, canonicalisation and deduplication detail;
- separate application, document, AI generation, export, wallet, location, reporting and System Data chapters;
- multiple before/problem/change/current architecture stories;
- the sanitised rich-profile CV failure and recovery case study;
- E2E/showcase automation and the full capacity investigation rather than headline totals;
- multi-repository contract/revision/checksum discipline;
- selected short, privacy-reviewed code excerpts;
- a domain-level test/evidence matrix and full technical appendix;
- a claim-level internal evidence map and machine-readable service catalogue;
- additional current and synthetic-fixture screenshots with explicit provenance.

## Editorial changes

- Pages 1–5 remain recruiter-readable.
- Later pages become deliberately denser and use tables, timelines, code, before/after flows and implementation notes.
- “What exists” is separated from “how it evolved” and “what is still unproven”.
- The dossier describes AI-assisted engineering accurately: Bernard conceived and directed the product, reviewed decisions and outputs, integrated and tested the system, and used failures in realistic operation to drive architectural correction.

## Evidence and privacy changes

- Historical claims now cite internal PR/issue/file evidence in `engineering-portfolio-evidence.md`.
- The appendix catalogue is generated from `engineering-service-catalogue.json`.
- Fixture screenshots are labelled as deterministic; live/manual screenshots are privacy-cropped.
- No real CV, email address, phone number, credential, cookie or private environment value is included.
