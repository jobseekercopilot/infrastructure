# Detailed portfolio change report

## Baselines retained

The 16-page concise portfolio remains available as v1. The former 42-page
engineering dossier remains recoverable from Git history; v3 replaces its
generated output in the application pack.

## Why v3 was produced

The v2 dossier was accurate but read too much like an internal architecture
audit. It devoted an eight-page run to generated-content mechanics, defended
the development process too prominently, used private PR references that an
external reader could not inspect, and compressed the service catalogue into
type as small as 6.9pt. Visual review also found a clipped timeline, an
overflowing location callout, low-contrast dark-page chips, unreadable tall
screenshots and an unconvincingly sparse example CV.

## What v3 changes

- leads with working product paths and independent confidence evidence;
- removes the authorship/process-defence page and keeps attribution restrained;
- compresses generated-content internals into two pages about the durable
  operation, grounding and recovery;
- separates dated deterministic regression, bounded live execution,
  persistent-manual use and local capacity evidence;
- adds a successful 12 August live-provider/OpenAI showcase result and uses its
  richer synthetic generated CV as privacy-safe artifact evidence;
- distinguishes deployed AWS landing-stack evidence from the calculated,
  not-yet-deployed authenticated-application AWS candidate;
- adds a projected ECS/RDS/S3/Secrets/CloudWatch/SES topology and explicit
  implementation gates;
- replaces the three-page cramped appendix with a seven-page, 31-repository
  catalogue naming purpose, callers, downstream calls and state;
- corrects current communication truth for Payment, Job Finder, Location and
  OpenWeb Ninja JSearch;
- raises body, table, dense and catalogue type sizes and repairs the known SVG,
  contrast, screenshot and pagination defects;
- removes private PR-number references from the shareable prose.

## Evidence and privacy

Claims remain tied to dated reports and source in
`engineering-portfolio-evidence.md`. Live evidence is not presented as a
reliability guarantee, local capacity is not presented as AWS capacity, and
the public landing deployment is not presented as the authenticated platform.

The embedded generated CV uses the fictional System Data persona from the
live showcase. No real CV, contact detail, credential, cookie, secret or
private environment value is included.
