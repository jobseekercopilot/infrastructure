## Workload and architecture summary

Job Seeker Copilot's primary cloud workload is a UK public beta hosted in
AWS London (`eu-west-2`). The lean plan uses one bounded ECS/EC2
`m7i.2xlarge` fleet, an ALB/WAF edge, one NAT Gateway, a private encrypted
`db.t4g.medium` PostgreSQL instance with seven logical service databases,
versioned/KMS-encrypted S3 document storage, ECR, Secrets Manager, SES hooks,
CloudWatch and AWS Backup. Twenty-seven application services use private
service discovery and per-service security groups. Google Maps, when separately
approved, is a specialist external API—not core hosting.

The modular HA upgrade is intentionally off: it would add a second node/NAT and
Multi-AZ RDS only after a new capacity/cost review. Nothing autoscaled beyond
one node in the lean default.
